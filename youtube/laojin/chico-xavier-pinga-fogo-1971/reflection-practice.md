# 讓善意落地：日常反思與練習

> 本頁是新增加的閱讀輔助，不是奇科的逐字引言，也不是 Jones 已親自確認採納的信條。請回到 [原稿](./transcript.md) 對照上下文。

## 每天三個簡短問題

**晨間：** 今天我能主動做的一件小善事是什麼？

**遭遇摩擦：** 我能否同時做到不報復、尊重他人，以及清楚表達界線？

**睡前：** 今天有哪個時刻我選擇理解而不是立即評判？有需要補救的傷害嗎？

## 七個閱讀入口

| 主題 | 自省問題 | 小行動 |
| --- | --- | --- |
| 生命有限 | 如果今天值得好好度過，我會如何使用這一小時？ | 真正關心一位身邊的人 |
| 放下執著 | 我是否仍因舊事持續懲罰自己或他人？ | 重新看見當下能做的選擇 |
| 面對弱點 | 哪種情境最容易讓我失去耐心？ | 回覆前先停頓數秒 |
| 面對苦難 | 我能提供什麼實際支持，而非替對方解釋原因？ | 問一句「我能怎麼幫你？」 |
| 愛與界線 | 我有沒有把寬恕誤解成必須接受再次傷害？ | 溫柔且明確地說出界線 |
| 恐懼與平靜 | 我的恐慌會不會增加旁人的負擔？ | 先穩定語氣，再處理問題 |
| 信仰與行動 | 價值觀是否反映在我的行動，而非只有言語？ | 以一件具體善行代替宣稱 |

## 三個提醒

1. 從值得實踐的倫理啟發出發，不必先接受整套輪迴、通靈等超自然說法。
2. 不把疾病、心理感受、夢境或死亡的靈性敘述取代醫學、心理照護與可檢驗的證據；也不以「業力」苛責病人或受害者。
3. 寬恕不等於容忍虐待；善良、界線、安全與自主可以同時成立。
