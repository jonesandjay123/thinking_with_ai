## 11/20 起步版：最值得先知道的 7 件事

1. **主線先解鎖工具與銀行，再探索。** 第一章不要只靠零星搶收銀機累積資金。
2. **Shirley 的蘭姆酒先交付，再查酒鋪後面的怪聲。** 提早開戰可能暫時封住商店。
3. **Lab Fees 後室密碼：`0420`。** 線索在店內工作桌記事本背面的便條。
4. **Fishing Shacks 從西南方上島。** 帶長槍，搜小紅屋與碼頭大屋，別漏消音步槍。
5. **留意第一章 Lucia 邀請的陽台冥想。** 該事件可能錯過，是否影響獎盃仍待確認。
6. **秘籍不是開局輸入就生效。** 兩個攻略站都指向「通關＋完成各自解鎖條件」，啟用後會停用存檔與獎盃／成就。
7. **大腳怪不只是預告片傳聞。** 兩站已刊出沼澤遭遇與 Kirk 支線，但完整支線的角色／章節條件仍有衝突，見專文。
